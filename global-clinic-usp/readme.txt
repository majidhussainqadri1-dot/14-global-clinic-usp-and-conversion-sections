Places the Global Cloud Clinic Network proposition across four approved high-visibility locations.

== Description ==

This modular American English plugin adds:

* A two-audience Global Clinic hero on the public home page.
* A dedicated Doctor Portal page with six professional benefits and direct application access.
* A patient global-access banner above the verified doctor search experience.
* A dedicated Our Mission page and a public footer link.
* A highlighted Doctor Portal link in compatible Sabri platform navigation.
* Responsible wording for commissions, geographic platform access, verification, organic discoverability, and applicable local laws.

The plugin integrates automatically with the Sabri Platform Foundation, Doctors Directory and Discovery, Worldwide Clinic, and Global Doctor Onboarding modules when they are active. It also works independently through its shortcodes and fallback URLs.

== Installation ==

1. Open WordPress Admin > Plugins > Add New > Upload Plugin.
2. Upload this ZIP file and select Install Now.
3. Activate Global Clinic USP and Conversion Sections.
4. Open Settings > Global Clinic USP and confirm all four placements are enabled.
5. Review the automatically created Doctor Portal and Our Mission pages.
6. Clear the Hostinger and browser caches, then test the home page and Doctors page in a private browser window.
