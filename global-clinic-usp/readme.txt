Provides policy-safe Global Clinic conversion sections for the Sabri Social Homeopathy Platform.

== Description ==

This modular American English plugin adds:

* A two-audience Global Clinic conversion hero on the public home page.
* A dedicated Doctor Portal page with six professional benefits and direct application access when a valid destination exists.
* A patient global-access banner on compatible verified-doctor and Worldwide Clinic pages.
* A dedicated Our Mission page and an optional public footer mission link.
* A Doctor Portal destination registered through the Unified Application Shell navigation filter.
* Neutral, transparent business-policy wording until one platform-wide commission and payment policy is approved and implemented.
* Safe page creation that never overwrites or republishes existing page content.
* Validated page destinations, duplicate-output protection, instance-safe IDs, translation-ready strings, conditional assets, health checks, safe repair, and plugin-settings rollback.

The plugin integrates through WordPress shortcodes, the Unified Application Shell destination filter, and guarded content placement. It does not perform regex or string surgery on companion-plugin HTML.

== Installation ==

1. Upload and activate the plugin on staging.
2. Open Settings > Global Clinic USP.
3. Review the Doctor Portal and Our Mission health report.
4. Resolve any page slug or content conflict without overwriting existing content.
5. Clear caches and complete staging acceptance before live promotion.
