Canonical File 14 implementation for approved Worldwide Clinic value-proposition content, ethical conversion journeys, claim governance, destination contracts and privacy-minimized measurement.

== Description ==

File 14 owns:

* Approved patient and doctor value-proposition blocks.
* Find a Global Doctor and Start Your Global Clinic CTA content and File 20 placement contracts.
* Claim evidence, owner, effective date, review date, withdrawal and version history.
* Canonical routes `/global-clinic/` and `/clinic/how-it-works/`.
* Versioned destination contracts to Files 07, 08 and 09.
* Consent-gated, Global-Privacy-Control-aware, privacy-minimized funnel events and thresholded summaries.
* Governed copy, placement and experiment state machines.
* Complete File 14-owned American English, Urdu and Arabic interface chrome with RTL/LTR parity checks.
* Low-bandwidth/reduced-data rendering and nonessential-measurement suppression.
* System Check, safe mode, owner-scoped repair and option-snapshot rollback.

File 14 does not own doctor profiles, verification evidence, clinic records, appointments, payments, clinical records, global navigation or visual-system truth.

== Brand and navigation ==

The exact primary File 14 brand token follows the fresh central plan: Sabri Green `#087A4E`. File 20 remains the sole owner of the global shell and global navigation. == Installation ==

1. Install only on staging first.
2. Verify database and file backups and a restore rehearsal.
3. Activate the plugin.
4. Review Settings → Global Clinic USP.
5. Verify File 07, 08, 09, 20 and 25 contracts.
6. Test `/global-clinic/`, `/clinic/how-it-works/`, all destination/degraded states, English LTR, Urdu/Arabic RTL, keyboard, screen reader, 320–1920px and 400% zoom.
7. Test `Save-Data`, reduced-motion, consent withdrawal, Global Privacy Control, provider outage, queue retry/dead-letter, fresh install/upgrade and rollback.
8. Obtain explicit Founder acceptance before production deployment.

Activation is idempotent and never overwrites legacy pages or companion records. Legacy SGC data is inventoried read-only.

== Privacy ==

Public content works without measurement. Attribution and funnel events require explicit consent and are disabled when Global Privacy Control is requested. Attribution capture is restricted to File 14 acquisition routes, signed, bounded to 30 days and contains only approved campaign fields. Funnel summaries suppress small totals below ten events. No health, identity evidence, message, payment or appointment content is collected by File 14. Nonessential browser measurement is also suppressed for Save-Data clients.
