## Two new R46 SOURCE defects: documented before ANY edits

**R46-D01 (FR016/FUT04):** `GCU_Future_Intelligence::claim_freshness()` uses `strtotime( $row['review_due_at'] . ' UTC' )` and analogous expiry and then `!$review || $review>$now`. A populated invalid timestamp parsed as `false` evaluates as `!false` and is incorrectly marked fresh. This may let malformed date evidence pass `parity_status()` or evidence drawer freshness instead of blocking. Distinguish NULL/empty unbounded expiry from a present invalid field; invalid nonempty, noncanonical or past expiry/review time must **fail closed**, no new trust claims.

**R46-D02 (FUT05/FUT08/FR016):** `GCU_Future_Intelligence::parity_status()` scans active Public Copy blocks, but directly reads `$block['title']`, `$block['body']`, `$block['cta_label']` without row-shape validation; malformed records/DB source return could generate PHP undefined field warnings while `dark_pattern_scan(' ')` falsely treats them as clean. Require each inspected row is an array with the complete expected scalar text fields; if not, add `active_copy_row_unverified` issue and never certify `ok=true`. Keep bounded scan 501 sentinel and policy checks in place.
